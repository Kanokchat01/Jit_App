# JitDee - AI Mental Health Assessment App

## Overview
JitDee is a full-stack mobile application designed for mental health screening using AI and psychological assessment tools.

## Features
- PHQ-9 Mental Health Screening
- Deep Assessment (TMHI-55)
- AI-based Emotion Detection (TensorFlow Lite)
- Real-time data with Firebase
- Appointment system for high-risk users

## Tech Stack
- Flutter (Mobile App)
- Python / Backend API
- Firebase (Auth + Firestore)
- TensorFlow Lite (AI Model)

## AI & Data
- Emotion classification (angry, happy, neutral, sad)
- Real-time inference optimization
- Threshold tuning and smoothing


## Future Improvements
- RAG-based chatbot for mental health support
- Cloud AI model deployment
